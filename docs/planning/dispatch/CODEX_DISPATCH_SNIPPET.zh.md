```text
并给出任务链接(View task);不要伪造 PR URL。
监督者/发布席位随后用平台 Create PR 或控制中心 codex cloud apply 完成发布。
摘要结尾必须含 context_remaining;若已有 PR URL 则必须写出。
目标 base 分支: <填 stream/* 或编排分支;勿默认假定 main>
```
