## 任务目标

实现 Phase 0 内部可运行的项目控制 CLI 与机器可读状态合约，使编排轮能够以 revision 检查方式原子更新状态、创建或推进最多三个互不重叠的 Ralphy stream，并通过集成队列串行化候选合并。

## 必须满足的验收标准

- 状态变更必须带 revision / compare-and-swap 检查；过期 revision 必须失败且不得部分写入。
- 生命周期状态必须受控；非法任务状态迁移必须被拒绝。
- 当前授权阶段内的 Phase 0 操作必须可执行；Phase 1 操作必须保持拒绝，直到人类显式变更 `PLAN.md` 授权。
- 工作者不得把任务标记为 `verified` 或 `done`；验证与完成只能由授权编排/门禁路径写入。
- 最多三个互不重叠的 Ralphy streams 可并行存在；每个 stream 内部必须保持顺序单 mutation owner。
- 集成队列必须串行化 candidate merges，并记录顺序、来源 stream、candidate SHA 与证据引用。
