## WEAKER CASES CONSIDERED AND RULED — recorded, not merged with the above

1. `The sign does not matter here.` (`..._question_2_wrong_7`, both P1Q2 and
   P2Q2). It is true that the sign of the fraction has no bearing on *whether*
   the decimal terminates or repeats, so a strong student could reach for it.
   **Ruled not a defect.** In P1Q2 the stem asks which *outcome of the long
   division* is not possible; this is not an outcome at all, so it cannot be a
   correct selection. In P2Q2 the stem asks for a statement *about the result*,
   and about the result the sign plainly does matter — a/b negative yields a
   negative decimal. On the natural reading of each stem the choice is false,
   and this ruling is what keeps `More than one listed choice is correct`
   (`wrong_5`) false in both items.

2. P2Q3 keys `If x = 0.666..., then 3x = 2.` while the answer key's own
   derivation produces `9x = 6` (which is not among the eight choices). This is
   a true statement (x = 2/3 ⇒ 3x = 2) and the stem itself hands the student
   x = 2/3 via Mia's claim, so it is producible from the assignment alone —
   criterion 5 satisfied. **Ruled not a defect**, but flagged as an asymmetry:
   the parallel item P1Q3 keys `99x = 27`, which *is* the key's own equation.
   A fixer touching this package should not "correct" `3x = 2` — it is right.

3. Both Q2 items present eight choices where the assignment prints only options
   A/B/C. **Ruled not a defect** under criterion 5: the keyed choice is verbatim
