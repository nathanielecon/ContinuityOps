DEFECTS

  Part 1 Question 1 | criterion 2 (with 7) | 1_1_part_1_question_1_wrong_1
    found:  +-18 and -18
    why:    The keyed answer is "+18 and -18". This distractor is the same
            string with one extra character. It has two readings and both are
            bad. Read as un-typeset "±18 and -18", the first element ranges
            over +18, which is exactly the correct signed number for an 18 m
            rise, so a student who reads ± as "either sign, including the right
            one" selects it and scores zero under all-or-nothing. Read as a
            typographical slip for "+18 and -18", it is literally the key. The
            rubric names this exact case (a ± written "+-" where the key writes
            "+18 and -18"). Note the sibling item P2Q1 avoids the problem: its
            wrong_1 is "24 and +24", where bare 24 is unambiguously the wrong
            sign for a descent. P1Q1 needs the same treatment.
    fix:    Replace the choice text with
            &lt;p&gt;+18 and +18&lt;/p&gt;
            (false: the descent must be negative; no sign ambiguity; not a
            near-duplicate of the key).

  Part 1 Question 2 | criterion 2 (with 4) | 1_1_part_1_question_2_wrong_4
    found:  a + b = 0
    why:    The stem asserts it: "We are told that \(a < 0\), \(b > 0\), and
            \(a + b = 0\)." A choice that restates a hypothesis of the stem is
            true by construction. Worse, under the stem's own constraints it is
            not merely true but logically equivalent to the keyed answer: with
            a < 0 and b > 0 we have |a| = -a and |b| = b, so
            |a| = |b|  <=>  -a = b  <=>  a + b = 0.
            The Part 1 key for Lesson 1-1 Q2 reads "Answer: |a| = |b| (or
            equivalent)", so the key itself admits equivalent forms while the
            scoring negates this one. A student who reasons correctly and ticks
            both scores zero. (The counter-argument, that the stem asks for an
            equation "about the absolute values" and a + b = 0 is not one, is
            noted; it does not rescue the choice, because the defect is that a
            stem-given truth is punished, and the key's "or equivalent" makes
            the punishment explicit.)
    fix:    Replace the choice text with
            &lt;p&gt;|a| = 2|b|&lt;/p&gt;
            (an absolute-value equation, unambiguously false: |a| = |b| and
            b != 0, so |a| = 2|b| would force b = 0, contradicting b > 0).

  Part 2 Question 2 | criterion 2 (with 4) | 1_1_part_2_question_2_wrong_4
    found:  p + q = 0
    why:    Identical defect, mirrored. Stem: "We are told that \(p > 0\),
            \(q < 0\), and \(p + q = 0\)." With p > 0 and q < 0,
            |p| = p and |q| = -q, so |p| = |q| <=> p = -q <=> p + q = 0.
            Part 2 key: "Answer: |p| = |q| (or equivalent)".
    fix:    Replace the choice text with
            &lt;p&gt;|p| = 2|q|&lt;/p&gt;

  Part 2 Question 4 | criterion 7 | stem mattext of item 1_1_part_2_question_4
    found:  &lt;p&gt;Order from least to greatest: $6,\ -2,\ 4$&lt;/p&gt;
    why:    Every other math span in this package uses \(...\), including the
            parallel item P1Q4: "Order from least to greatest: \(-3,\ 8,\ -1\)".
            Canvas's MathJax configuration for these packages processes \(...\)
            only; a $...$ span is not a delimiter, so the student sees the
            literal characters "$6,\ -2,\ 4$" - dollar signs and a backslash-
            space macro included. The numbers themselves are right (assignment:
            "Q4. Order from least to greatest: 6, -2, 4"; key: "-2, 4, 6"), so
            this is a rendering defect, not a mathematical one, but it makes the
            stem read as garbage.
    fix:    Replace the stem math span with
            \(6,\ -2,\ 4\)
            i.e. the mattext becomes
            &lt;p&gt;Order from least to greatest: \(6,\ -2,\ 4\)&lt;/p&gt;
            followed by the unchanged "Canvas accuracy check" paragraph.
