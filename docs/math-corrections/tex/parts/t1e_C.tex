\lesson{Topic 1-4 Subtract Integers}

\question{Question 1}

\blockhead{Question}
At 6:00 PM, the temperature was $5$\degF. By midnight, the temperature was $-8$\degF. Write at least two mathematical expressions that correctly represent the distance between the two temperatures.

\checked{Distance $13$\degF; any correct distance expression such as $\abs{5-(-8)}$, $\abs{-8-5}$, $5-(-8)$, $\abs{-8}+5$}

\blockhead{What the question is asking}
This question asks for math phrases that show how far apart $5$\degF and $-8$\degF are.

\blockhead{Important words}
\begin{words}
  \item An \term{operation}is a math action. Add joins amounts. Subtract takes away or finds a difference. Multiply makes equal groups. Divide splits into equal groups.
  \item An \term{expression}is a math phrase made of numbers and operation signs.
  \item \term{Distance}between two numbers is how far apart they are. Distance is never negative.
  \item A \term{difference}is the answer to a subtraction problem (here, one temperature minus the other).
  \item \term{Absolute value}\barsym\ turns a difference into a positive distance.
  \item \term{Subtracting a negative}: $a-(-b) = a+b$.
  \item To \term{flip}the order means subtract the other way; absolute value keeps the distance positive.
  \item $8$\degF below zero means $-8$\degF.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item The two temperatures are $5$ and $-8$.
  \item Distance $= \abs{5-(-8)}$.
  \item Subtracting a negative changes to adding: $5 - (-8) = 5 + 8$.
  \item Add: $5 + 8 = 13$.
  \item Absolute value: $\abs{13} = 13$.
  \item Flip the subtraction order to make another expression: $\abs{-8-5}$.
  \item Work inside the bars: $-8 - 5 = -13$.
  \item Take the absolute value: $\abs{-13} = 13$.
  \item The expression $5-(-8)$ is also valid. Its value is the $13$ found above.
  \item Another expression is $\abs{-8} + 5$.
  \item First find the absolute value: $\abs{-8} = 8$.
  \item Then add: $8 + 5 = 13$.
\end{steps}

\finalans{Distance $13$\degF; e.g. $\abs{5-(-8)}$, $\abs{-8-5}$, $5-(-8)$, $\abs{-8}+5$}

\numline{-8}{6}{2}{-8,5}

\begin{center}
Marked points: $-8$\degF\ and $5$\degF; distance $= 13$.
\end{center}

\blockhead{Why this makes sense}
From $5$ down to $0$ is $5$ degrees, then down to $-8$ is $8$ more, total $13$. Check: $5 + 8 = 13$. Any expression that equals $13$ works.

\question{Question 2}

\blockhead{Question}
Two birds are flying in the sky. Bird A is $150$ feet above sea level. Bird B is $120$ feet above sea level. Write at least two expressions that represent the vertical distance between the birds.

\checked{Distance $30$ ft; e.g. $\abs{150-120}$, $\abs{120-150}$, $150-120$}

\blockhead{What the question is asking}
This question asks for math phrases that show how far apart the birds are up and down.

\blockhead{Important words}
\begin{words}
  \item \term{Vertical}means up and down (not side to side).
  \item \term{Vertical distance}means the up-down distance between two heights.
  \item A \term{positive}number is greater than zero.
  \item A \term{negative}number is less than zero.
  \item \term{Above sea level}means a positive height.
  \item An \term{operation}is a math action. Add joins amounts. Subtract takes away or finds a difference. Multiply makes equal groups. Divide splits into equal groups.
  \item An \term{expression}is a math phrase made of numbers and operation signs that names a value.
  \item \term{Absolute value}keeps distance positive even if you subtract in either order.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item Heights: Bird A is $150$ ft. Bird B is $120$ ft.
  \item Both are above sea level, so both heights are positive.
  \item Distance $= \abs{150-120}$.
  \item Compute $150 - 120 = 30$.
  \item So $\abs{150-120} = 30$.
  \item Flipped order (subtract the other way; absolute value keeps distance positive): $\abs{120-150} = \abs{-30} = 30$.
  \item Also: $150 - 120 = 30$ (already positive).
\end{steps}

\finalans{Distance $30$ ft; e.g. $\abs{150-120}$, $\abs{120-150}$, $150-120$}

\blockhead{Why this makes sense}
The higher bird is $30$ feet above the lower bird. Absolute value protects you if you subtract the other way.

\question{Question 3}

\blockhead{Question}
Two fish are swimming beneath the water. Fish A's elevation is $-25$ feet relative to sea level. Fish B's elevation is $-40$ feet relative to sea level. Write at least two expressions that represent the vertical distance between the fish.

\checked{Distance $15$ ft; e.g. $\abs{-25-(-40)}$, $\abs{-40-(-25)}$, $40-25$}

\blockhead{What the question is asking}
This question asks for math phrases that show how far apart $-25$ ft and $-40$ ft are up and down.

\blockhead{Important words}
\begin{words}
  \item A \term{positive}number is greater than zero.
  \item A \term{negative}number is less than zero.
  \item \term{Below sea level}is a negative height.
  \item \term{Vertical distance}means how far apart two heights are up and down.
  \item A \term{signed number}has a plus or minus sign that shows direction.
  \item A \term{difference}is the answer to a subtraction problem.
  \item An \term{expression}is a math phrase that names a value.
  \item \term{Absolute value}\barsym\ means distance from zero, so it is never negative.
  \item \term{Distance}is still positive. Use absolute value of the difference.
  \item Subtracting a negative: $-25 - (-40) = -25 + 40$.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item Positions: Fish A at $-25$ ft. Fish B at $-40$ ft.
  \item Both are below sea level, so both heights are negative.
  \item Distance $= \abs{-25-(-40)}$.
  \item Inside: $-25 - (-40) = -25 + 40 = 15$.
  \item Absolute value: $\abs{15} = 15$.
  \item Flipped order (subtract the other way): $\abs{-40-(-25)} = \abs{-40+25} = \abs{-15} = 15$.
  \item Using depths as positive amounts: deeper minus shallower $40 - 25 = 15$.
\end{steps}

\finalans{Distance $15$ ft; e.g. $\abs{-25-(-40)}$, $\abs{-40-(-25)}$, $40-25$}

\blockhead{Why this makes sense}
Fish B is $15$ feet deeper than Fish A. Same distance whether you use signed heights or positive depths.

\question{Question 4}

\blockhead{Question}
An elevator starts on floor $-3$, travels to floor $8$, then returns to floor $-1$. What total distance does it travel?

\checked{$20$ floors}

\blockhead{What the question is asking}
Find two whole-number distances across ground level and add them.

\blockhead{Important words}
\begin{words}
  \item \term{Positive floors}are above ground; \term{negative floors}are below ground.
  \item \term{Distance}is always positive.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item From $-3$ to $8$: $\abs{8-(-3)} = 11$.
  \item From $8$ to $-1$: $\abs{-1-8} = 9$.
  \item Add: $11 + 9 = 20$.
\end{steps}

\finalans{$20$ floors}

\blockhead{Why this makes sense}
Each leg covers a whole number of floors, so the two distances add to $20$.

\lesson{Topic 1-5 Add and Subtract Rational Numbers}

\question{Question 1}

\blockhead{Question}
Another bank account starts with $\$200$. The bank charges a fee of $\$15$ each month, but \emph{only} if the balance is below $\$250$. If there are no other deposits or withdrawals, what is the balance after 4 months?

\checked{$\$140$}

\blockhead{What the question is asking}
This question asks for the money left after 4 months when a $\$15$ fee applies only while the money in the account is below $\$250$.

\blockhead{Important words}
\begin{words}
  \item A \term{balance}is the money in the account.
  \item A \term{fee}subtracts money when the rule says so.
  \item \term{Below}$\$250$ means the balance is less than $\$250$.
  \item To \term{compare}means decide whether one number is less than, equal to, or greater than another.
  \item The symbol $<$ means ``is less than.''
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item Start: $\$200$. Compare to $\$250$: $\$200 < \$250$, so the fee applies.
  \item Month 1: $\$200 - \$15 = \$185$. Still $\$185 < \$250$, fee will apply again.
  \item Month 2: $\$185 - \$15 = \$170$. Still below $\$250$.
  \item Month 3: $\$170 - \$15 = \$155$. Still below $\$250$.
  \item Month 4: $\$155 - \$15 = \$140$. Still below $\$250$.
  \item Check another way: 4 fees of $\$15$ is $4 \times \$15 = \$60$. Then $\$200 - \$60 = \$140$. Same answer.
\end{steps}

\finalans{$\$140$}

\blockhead{Why this makes sense}
The account never reaches $\$250$, so the fee hits every month. Four fees remove $\$60$ from $\$200$, leaving $\$140$.

\question{Question 2}

\blockhead{Question}
At 6:00 PM, the temperature is $-3.75$\degC. It drops $2.4$\degC, then drops $1.85$\degC. What is the temperature at midnight?

\checked{$-8$\degC}

\blockhead{What the question is asking}
Combine a negative starting temperature and two negative changes.

\blockhead{Important words}
\begin{words}
  \item A \term{drop}is a negative change.
  \item A \term{terminating decimal}ends.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item $-3.75 - 2.4 - 1.85 = -8.00$.
  \item Remove unnecessary zeros: $-8$.
\end{steps}

\finalans{$-8$\degC}

\blockhead{Why this makes sense}
Both drops move the temperature farther below zero.

\question{Question 3}

\blockhead{Question}
A lookout is $\mixed{2}{1}{2}$ miles above sea level. A mountain base is $1.75$ miles below sea level. What is the vertical distance?

\checked{$4.25$ miles}

\blockhead{What the question is asking}
Find distance between a positive mixed number and a negative decimal.

\blockhead{Important words}
\begin{words}
  \item \term{Above sea level}is positive.
  \item \term{Below sea level}is negative.
\end{words}

\blockhead{Work the problem one tiny step at a time}
\begin{steps}
  \item $\mixed{2}{1}{2} = 2.5$.
  \item $\abs{2.5-(-1.75)} = 4.25$.
\end{steps}

\finalans{$4.25$ miles}

\blockhead{Why this makes sense}
The locations lie on opposite sides of sea level, so their distances from zero add.
